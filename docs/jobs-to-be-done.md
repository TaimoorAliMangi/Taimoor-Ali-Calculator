# Jobs to be done

Status: UAT feedback approved for implementation 13 October 2026; verified locally; cloud checks pending.

| ID | Role | Job |
|---|---|---|
| J1 | Prospective borrower | When I am exploring a housing-finance scenario, I want to enter a permitted property and borrowing amount, so I can estimate financing within the calculator's scheme limits. |
| J2 | Prospective borrower | When I compare loan tenures, I want to understand initial and later monthly payments, so I can judge the long-term commitment. |
| J3 | Prospective borrower / family adviser | When I plan upfront funds, I want to see estimated equity and project cost, so I can understand the cash contribution implied by my loan. |
| J4 | All public roles | When I inspect the repayment plan, I want yearly payment and balance figures, so I can understand how debt reduces. |
| J5 | Family / housing-finance adviser | When I explain a scenario to someone else, I want clear assumptions and limitations, so I can avoid presenting estimates as bank guarantees. |
| J6 | All public roles | When I use a phone or keyboard, I want readable and accessible controls, so I can calculate without assistance. |
| J7 | All public roles | When I enter financial scenarios online, I want local calculations and safe handling of inputs, so I can use the calculator without submitting personal financial records. |
| J8 | All public roles | When I help with a housing-finance decision, I want role-appropriate guidance, so I can focus on the information relevant to my situation. |
| J9 | All public roles | When I prefer Urdu, I want to switch language without losing my scenario, so I can understand the same estimate in my preferred language. |
| J10 | Prospective borrower | When I compare borrowing amounts, I want a principal slider, so I can adjust the loan quickly. |
